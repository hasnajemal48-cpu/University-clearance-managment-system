# 2. Functional Requirements
# 2.1 Student Requirements
FR-01: The system shall allow students to register and log in.
FR-02: The system shall allow students to view their personal information.
FR-03: The system shall allow students to submit clearance requests.
FR-04: The system shall allow students to track clearance progress.
FR-05: The system shall allow students to view office clearance statuses.
FR-06: The system shall allow students to view their final clearance results.
# 2.2 Department Head Requirements
FR-07: The system shall allow the department head to log in.
FR-08: The system shall display students requesting departmental clearance.
FR-09: The system shall allow the department head to check departmental obligations.
FR-10: The system shall allow the department head to approve or reject departmental clearance.
FR-11: The system shall maintain departmental clearance history.
# 2.3 Admin Requirements
FR-12: The system shall allow the admin to manage student records.
FR-13: The system shall allow the admin to manage user accounts.
FR-14: The system shall display submitted clearance requests.
FR-15: The system shall allow the admin to record clearance results from all university offices.
FR-16: The system shall allow the admin to view overall student clearance status.
FR-17: The system shall allow the admin to approve or reject final clearance.
FR-18: The system shall generate clearance reports.
# 2.4 Dorm Officer Requirements
FR-19: The system shall allow the dorm officer to view student dormitory information.
FR-20: The system shall allow the dorm officer to check dormitory obligations.
FR-21: The dorm officer shall provide clearance decisions to the admin.
# 2.5 Cafeteria Officer Requirements
FR-22: The system shall allow the cafeteria officer to view student cafeteria information.
FR-23: The system shall allow the cafeteria officer to check cafeteria obligations.
FR-24: The cafeteria officer shall provide clearance decisions to the admin.
# 2.6 Library Officer Requirements
FR-25: The system shall allow the library officer to view student library records.
FR-26: The system shall allow the library officer to check borrowed books and outstanding obligations.
FR-27: The library officer shall provide clearance decisions to the admin.
#2.7 Security Guard Requirements
FR-28: The system shall allow the security guard to view student security-related records.
FR-29: The system shall allow the security guard to check security clearance requirements.
FR-30: The security guard shall provide clearance decisions to the admin.
# 2.8 Finance Officer Requirements
FR-31: The system shall allow the finance officer to view student financial records.
FR-32: The system shall allow the finance officer to check cost-sharing obligations.
FR-33: The finance officer shall provide financial clearance decisions to the admin.
